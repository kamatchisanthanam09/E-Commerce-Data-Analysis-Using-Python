# E-Commerce Data Analysis Using Python

## Project Overview
This project analyzes e-commerce sales data using Python
to understand sales performance, customer behaviour,
revenue trends, and profitability.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives
1. Analyze total sales revenue
2. Identify top-selling products
3. Analyze category-wise sales
4. Analyze region-wise sales
5. Calculate total profit
6. Identify monthly sales trends
7. Analyze customer purchase behaviour
8. Analyze payment methods

## Dataset
Synthetic E-Commerce Sales Dataset containing 1,000 orders.

## Conclusion
This project demonstrates data cleaning, exploratory
data analysis, and data visualization using Python.
